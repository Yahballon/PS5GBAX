# Install PS5GBA

(AI-assisted) Extract the PPSA99209 folder into `/data/homebrew/` or your usual ShadowMount homebrew location, then launch PS5GBA. Add `.gba` or ZIP ROMs under `/data/PS5GBA/games/` or `/mnt/usb0/homebrew/PS5GBA/games/`. Saves/config are kept separately under `/data/PS5GBA/`. See the README for additional paths and controls. First console validation is pending. No ROM or BIOS is included.
