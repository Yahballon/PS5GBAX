# Controls

(AI-assisted)

| DualSense | GBA / emulator |
|---|---|
| D-pad | D-pad |
| Cross | A |
| Circle | B |
| L1 / R1 | L / R |
| Options | Start in game |
| Create | Select |
| Touchpad press | Return to library |
| L2 held | Fast forward, audio muted |
| L3 + R3 + Up | Save state |
| L3 + R3 + Down | Load state |

Square on the library opens settings. Controller mappings and shortcut chords are configurable for one game or all games. Shortcuts consume their buttons so they do not also reach the emulated game. A shortcut held at launch must first be released. Emergency return: hold L1 + R1 + touchpad for two seconds. In All games settings, configure output resolution/VSync, NFS shares, library rescan/reset and recent-first ordering. Touchpad returns to the live library; it does not implement a separate in-game pause overlay.
